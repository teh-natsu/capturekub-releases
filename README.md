# CaptureKub — downloads

Installers for **CaptureKub** for Windows (x64). This repository holds only the released installers, not the source code.

- Every release has `SHA256SUMS.txt` signed by Nattapol Chaisri; CaptureKub installs an update only when the signature and checksum are right.
